# 🍰 Blissful Sweets

## 👩‍🍳 Brand Identity
* **Brand Name:** Blissful Sweets
* **Target Audience:** Local foodies and event planners.

## 🛠️ Technical Features (Rubric Compliance)
This project incorporates all HTML/CSS modules required for the assignment:

* **Global Foundation:** Utilizes a global `<nav>` and `<footer>` across 5 pages, with colors managed via `:root` CSS variables.
* **Hero Section (Home):** Implements `vh` units and `background-size: cover` for a high-impact visual entrance.
* **Product Gallery (Grid):** A responsive 6-item grid using `display: grid` with `transform` scale effects on hover.
* **Data & Media (Blog):** Includes a `<table>` for pricing comparisons and an embedded `<video>` showing the baking process.
* **Pricing Tiers (Flexbox):** Three-tier service cards using `space-around` and `position: absolute` for "Best Value" badges.
* **Lead Gen Form:** A validated contact form with 5+ input types and custom `:focus` states.

## 📁 File Structure
- `index.html` - Landing Page
- `products.html` - Gallery
- `blog.html` - Industry News/Specs
- `pricing.html` - Service Tiers
- `contact.html` - Inquiry Form
- `css/main.css` - global styling
- `css/products.css` - product page styling
- `css/blog.css` - blog page styling
- `css/pricing.css` - pricing page styling
- `css/contact.css` - contact page styling
